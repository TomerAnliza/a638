# סוליטייר

משחק סוליטייר קלונדייק שרץ בדפדפן. HTML, CSS ו-JavaScript רגיל, בלי התקנות ובלי רשת.
פרויקט הדגמה לעבודה עם כמה סוכנים, מהשיעור «פיתוח עם סוכני-קוד» (A_638, 15 באוקטובר 2026).

## איך מריצים

```bash
npm start
```

ואז לפתוח בדפדפן את `http://localhost:8765`. אם `npm` לא מותקן:
`python3 -m http.server 8765 --directory src`.

מה רואים כשזה עובד: שולחן ירוק עם שבעה טורי קלפים, חבילה הפוכה למעלה משמאל, וארבעה מקומות ריקים לקרנות מימין.

## איך משחקים

- **המטרה:** להעלות את כל הקלפים לארבע הקרנות, כל קרן מ-A עד K באותה צורה.
- **בטורים:** מניחים קלף על קלף בצבע הפוך וערך נמוך באחד. אפשר להזיז רצף שלם. טור ריק מקבל רק מלך.
- **גרירה:** גוררים קלף או רצף ליעד. יעדים חוקיים מסומנים בזהב.
- **לחיצה על קלף:** מזיזה אותו למקום הטוב ביותר, קודם לקרן ואחר כך לטור.
- **לחיצה על החבילה:** מושכת קלף אחד או שלושה, לפי הבחירה בראש הדף. כשהחבילה נגמרת, לחיצה מחזירה אליה את הערימה.
- **ביטול מהלך:** מחזיר מהלך אחד, כמה פעמים שצריך.
- **השלמה אוטומטית:** מופיעה כשכל הקלפים גלויים והחבילה ריקה.

## בדיקות

```bash
npm test
```

בדיקות ללוגיקה של המשחק (`src/game.js`), ב-Node ובלי התקנות.
