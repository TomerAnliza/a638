# מודל המשחק

המסמך הזה מסביר איך `src/game.js` בנוי, כדי שאפשר יהיה להעביר אותו ל-Next.js בלי לשכתב.

## עיקרון

`game.js` טהור: אין בו DOM, טיימרים או גישה לדפדפן. הוא מקבל מצב ומחזיר מצב.
כל הציור והאירועים נמצאים ב-`app.js`.

## המצב

| שדה | משמעות |
|---|---|
| `stock` | חבילת המשיכה, הפוכה. הקלף העליון הוא האחרון במערך |
| `waste` | קלפים שנמשכו, גלויים. העליון הוא האחרון במערך |
| `foundations` | ארבע קרנות, לפי סדר הצורות `S, H, D, C`. כל קרן שייכת לצורה אחת |
| `tableau` | שבעה טורים. הקלף האחרון בטור הוא החשוף |
| `history` | תמונות מצב לביטול מהלך |
| `seed` | זרע הערבוב. אותו זרע נותן אותה חלוקה |

## הפעולות

מקור מהלך: `{ zone: 'waste' | 'foundation' | 'tableau', index?, row? }`. יעד: `{ zone: 'foundation' | 'tableau', index }`.

- `newGame`, `draw`, `move`, `undo` משנות את המצב.
- `canMove`, `getCards`, `bestMove`, `findFoundationMove`, `isWon`, `canAutoComplete` רק בודקות.

## החלטות עיצוב

- הקרנות קשורות לצורה (לא כל קרן מקבלת כל אס). פשטות הממשק גברה על חופש שאין לו ערך במשחק.
- מלך שכבר פותח טור לא עובר לטור ריק. המהלך חוקי אבל חסר תועלת, והוא היה מפריע ללחיצה האוטומטית.
- משיכה של שלושה: רק הקלף העליון בערימה זמין.
- הניקוד פשוט: קרן +10, ערימה לטור +5, חשיפת קלף +5, החזרה מקרן -15, מחזור חבילה במשיכה של אחד -100.
